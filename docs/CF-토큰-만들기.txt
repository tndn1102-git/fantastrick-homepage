Cloudflare 열쇠(API 토큰) 만들기 — 2분
================================================================
왜 필요한가
  지금 제 권한이 "보기만 가능" 이라, 도메인을 등록하고 메일 설정을
  옮겨 적는 일을 제가 못 합니다. 쓰기 권한 열쇠가 하나 있으면
  그 부분까지 전부 제가 합니다.


[1] 토큰 만드는 화면 열기
----------------------------------------------------------------
  https://dash.cloudflare.com/profile/api-tokens
  (오른쪽 위 프로필 → My Profile → API Tokens 로 가도 같습니다)

  [Create Token] 클릭
  맨 아래 [Create Custom Token] 옆의 [Get started] 클릭


[2] 이름
----------------------------------------------------------------
  Token name :  fantastrick-domain


[3] Permissions — 5줄을 추가합니다
----------------------------------------------------------------
  칸이 3개씩 있습니다. [왼쪽 = 범위] [가운데 = 항목] [오른쪽 = 권한]
  [+ Add more] 를 눌러 줄을 늘립니다.

    Account   |  Zone              |  Edit
    Account   |  Workers Scripts   |  Edit
    Zone      |  DNS               |  Edit
    Zone      |  Zone Settings     |  Edit
    Zone      |  Workers Routes    |  Edit

  ※ 가운데 항목 이름이 화면마다 조금 다를 수 있습니다.
    비슷한 이름이 보이면 그걸 고르고, 없으면 그 줄은 건너뛰세요.
    제가 받아서 시험해 보고 모자란 게 있으면 그때 알려드리겠습니다.


[4] Account Resources
----------------------------------------------------------------
    Include  |  (사장님 계정 이름 선택)


[5] Zone Resources  ← 여기가 중요합니다
----------------------------------------------------------------
    Include  |  All zones from an account  |  (사장님 계정 선택)

  ※ 특정 도메인 하나만 고르면 안 됩니다.
    fantastrick.co.kr 이 아직 Cloudflare 에 등록 전이라 목록에 없습니다.
    그래서 "All zones from an account" 로 두어야 새로 추가할 수 있습니다.


[6] TTL (유효기간) — 선택
----------------------------------------------------------------
  걱정되시면 오늘부터 1주일 정도로 짧게 잡으셔도 됩니다.
  기간이 지나면 저절로 죽습니다.


[7] 만들고 나면
----------------------------------------------------------------
  [Continue to summary] → [Create Token]

  ⚠️ 토큰 값은 이 화면에서 딱 한 번만 보입니다. 창을 닫으면 다시 못 봅니다.
     복사해서 저에게 알려주세요.

  받으면 제가 .env.local 에 넣어 보관합니다. (git 에 안 올라가는 파일입니다)
  일이 끝나면 이 화면에서 [Delete] 로 지우시면 됩니다.
