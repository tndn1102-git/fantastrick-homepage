Cloudflare 준비 — 순서를 바꿉니다 (2026-08-12 수정)
================================================================
처음엔 "토큰으로 도메인까지 추가하겠다" 고 했는데,
Account 권한 목록에 Zone 이 없습니다. 그 방식은 안 됩니다.

→ 도메인 추가는 화면에서 직접(1분), 나머지는 토큰으로 제가.
  이 편이 더 간단하고, 토큰 권한도 훨씬 좁게 줄 수 있어 안전합니다.


┌───────────────────────────────────────────────────────────┐
│ [1단계] 도메인 추가하기   ← 사장님 · 1분                  │
└───────────────────────────────────────────────────────────┘

  https://dash.cloudflare.com  접속

  [+ Add a domain]  (또는 Add a Site) 클릭
      ↓
  fantastrick.co.kr  입력
      ↓
  요금제 고르는 화면 → 맨 아래 Free (무료) 선택
      ↓
  Cloudflare 가 기존 설정을 자동으로 훑어옵니다 (몇 초)
      ↓
  "네임서버를 바꾸세요" 안내가 나옵니다
      ↓
  ⛔ 여기서 멈추세요. 아직 가비아에서 아무것도 바꾸지 마세요.


  ※ 지금 이 단계는 아무 영향이 없습니다.
    네임서버를 바꾸기 전까지 홈페이지·메일·TGC 전부 그대로 돌아갑니다.
    "등록만 해두고 아직 안 쓰는" 상태입니다.

  ※ 무료 요금제로 충분합니다. 유료 안 하셔도 됩니다.


┌───────────────────────────────────────────────────────────┐
│ [2단계] 토큰 만들기   ← 사장님 · 2분                      │
└───────────────────────────────────────────────────────────┘

  https://dash.cloudflare.com/profile/api-tokens
  [Create Token] → 맨 아래 [Create Custom Token] → [Get started]

  Token name :  fantastrick-domain

  Permissions — 4줄  ([+ Add more] 로 줄을 늘립니다)

      Account  |  Workers Scripts  |  Edit
      Zone     |  DNS              |  Edit
      Zone     |  Zone Settings    |  Edit
      Zone     |  Workers Routes   |  Edit

    ※ 가운데 칸은 글자를 치면 걸러집니다.
      "worker" / "dns" / "setting" / "route" 로 찾으시면 빨라요.
    ※ 없는 항목이 있으면 그 줄은 비워두고 넘어가세요.
      제가 시험해 보고 모자란 걸 정확히 알려드리겠습니다.

  Account Resources
      Include  |  (사장님 계정)

  Zone Resources   ← 1단계를 먼저 했으니 이제 고를 수 있습니다
      Include  |  Specific zone  |  fantastrick.co.kr

    ※ 이 도메인 하나에만 쓰도록 좁히는 게 안전합니다.
      목록에 fantastrick.co.kr 이 안 보이면 1단계가 아직 안 끝난 것입니다.

  TTL — 걱정되시면 1주일 정도로 짧게 잡으셔도 됩니다.

  [Continue to summary] → [Create Token]

  ⚠️ 토큰 값은 이 화면에서 딱 한 번만 보입니다. 창 닫으면 다시 못 봅니다.
     복사해서 알려주세요.


┌───────────────────────────────────────────────────────────┐

  · 새 홈페이지에 주소 연결 준비
