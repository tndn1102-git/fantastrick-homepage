NHN 알림톡 — 지금 바로 할 것 (발신번호 심사와 병렬)
================================================================
발신번호 심사를 기다릴 필요 없습니다. 알림톡은 문자망이 아니라
카카오 채널로 나가기 때문에 두 심사가 서로 무관합니다.

[1] 발신 프로필 등록  ← 심사 없음. 5분이면 끝납니다
----------------------------------------------------------------
  NHN Cloud 콘솔 > Notification Hub > 발신 정보 > 발신 프로필 관리
  [+ 발신 프로필 등록] 클릭

    · 발신 프로필 ID    = 카카오 채널 "검색용 아이디" (_로 시작하는 것)
                          center-pf.kakao.com > 관리 > 상세설정 에서 확인
    · 관리자 휴대폰 번호 = 채널 관리자 폰
    · 카테고리          = 서비스업 / 문화·레저 계열에서 방탈출에 가까운 것

  [토큰 요청] → 폰으로 온 6자리 입력 → [확인] → [등록]  = 끝

  ※ 미리 확인: center-pf.kakao.com 상세설정에서
     "채널 공개"와 "검색 허용"이 둘 다 ON 이어야 합니다. 꺼져 있으면 막힙니다.


[2] 알림톡 템플릿 등록 → 카카오 심사  ← 여기가 오래 걸립니다 (영업일 2~5일)
----------------------------------------------------------------
  같은 콘솔에서 알림톡 템플릿 등록

  [템플릿 이름]  예약확정안내

  [템플릿 내용] ↓ 아래 상자 안을 그대로 붙여넣기
  ----------------------------------------------------
  [판타스트릭] #{이름}님, 예약이 확정되었습니다.

  ▶ 테마 : #{테마}
  ▶ 일시 : #{날짜} #{시간}

  예약 시간 10분 전까지 도착해 주세요.
  방문해 주셔서 감사합니다.
  ----------------------------------------------------

  변수는 정확히 이 네 개입니다 (순서는 상관없습니다)
       #{이름}  #{테마}  #{날짜}  #{시간}

  ※ 가비아는 변수를 "순서"로 채워서 순서가 틀리면 사고가 났지만,
     NHN은 "이름"으로 채웁니다. 그래서 NHN에서는 순서 걱정이 없습니다.
     홈페이지 코드가 이미 이 네 이름으로 보내게 돼 있습니다.

  심사 반려되는 흔한 이유
    · 할인·이벤트 같은 홍보 문구 (정보성 메시지만 됩니다)
    · "채널 추가해주세요" 같은 유도 문구
    · 고정 문구 없이 변수만 있는 경우
    위 초안은 세 가지를 모두 피했습니다.


[3] 끝나면 저에게 알려주실 것 4개
----------------------------------------------------------------
    1) 발신 프로필의 senderKey        (발신 프로필 상세에 있음)
    2) 템플릿 코드                     (심사 승인 후 나옴)
    3) 알림톡 appKey                   (KakaoTalk Bizmessage 서비스)
    4) 알림톡 secretKey                (같은 곳)

  넣는 순간부터
      카톡 되는 손님   → 알림톡
      카톡 안 되는 손님 → 자동으로 문자
  로 갈립니다.


[참고] 발신번호 심사가 왜 그래도 필요한가
----------------------------------------------------------------
  알림톡 자체는 발신번호 없이도 나갑니다.
  다만 "카톡 안 되는 손님에게 문자로 대신 보내는" 기능이 발신번호를 씁니다.
  그래서 발신번호 승인 전까지는 알림톡만 나가고 문자 대체가 안 될 수 있습니다.
  둘 다 진행 중이니, 보통은 비슷한 시기에 함께 풀립니다.
