클라우드플레어 열쇠에 "방화벽 편집" 권한 더하기  (한 번만 하면 됩니다 · 약 1분)
=====================================================================

왜 하나요?
  /wp-admin/admin-ajax.php 라는 옛 워드프레스 주소를 밖에서 계속 두드리고 있습니다.
  하루 4,200번. 우리 코드에는 없는 주소라 100% 쓸모없는 요청입니다.

  지금도 404 로 끊고는 있지만, 그건 "서버가 깨어난 뒤에" 끊는 거라
  하루 요청 한도(10만 건)는 그대로 까먹습니다.
  관문(WAF)에서 끊어야 서버가 아예 안 깨어나고 요청 수에도 안 잡힙니다.

  지금 열쇠에는 그 규칙을 걸 권한이 없어서, 권한만 열어주시면 나머지는 제가 합니다.

  ※ 예약칸을 긁어가는 수집기(저쪽 회사)는 이 규칙과 무관합니다. 그대로 다 받아갑니다.


순서
-----
1) 열려 있는 페이지(클라우드플레어 API 토큰 목록)에서
   이름이 fantastrick 관련인 토큰 오른쪽 [...] -> [Edit] (편집) 클릭

   * 어떤 토큰인지 헷갈리면, 토큰 ID 가 아래와 같은 것을 고르세요:
     6ac10dace2551fcce23d577e69468996

2) Permissions(권한) 칸에서 [+ Add more] 를 눌러 아래 두 줄을 더합니다.

     Zone  |  Firewall Services  |  Edit
     Zone  |  Analytics          |  Read

   (한글 화면이면:  영역 | 방화벽 서비스 | 편집   /   영역 | 애널리틱스 | 읽기)

3) 맨 아래 [Continue to summary] -> [Save] 클릭

4) 저에게 "권한 열었어" 라고만 알려주세요.
   -> /wp-admin 차단 규칙을 걸고, 잘 걸렸는지 확인하고,
      하루 뒤 요청이 실제로 4,200건 줄었는지 다시 재서 보고합니다.


참고
-----
- 새 열쇠(토큰)를 만드는 게 아니라 "쓰던 열쇠에 권한을 더하는" 것이라
  .env.local 파일은 안 건드려도 됩니다. 값이 그대로예요.
- Analytics(애널리틱스) 읽기는 "어느 주소가 요청을 많이 먹는지" 보는 데 씁니다.
  지금은 권한이 없어서 그 조회(scripts/traffic-top.mjs)가 실패합니다.
- 이 열쇠는 2026-08-31 에 만료됩니다. 그때 다시 만들어야 합니다.
