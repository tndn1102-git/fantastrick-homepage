일부러 AI를 안 씁니다

환불 규정은 손님이 돈을 걸고 읽는 정보입니다. AI가 그럴듯하게 틀리면 실제 분쟁이 됩니다.

그래서 답은 전부 실제 운영 규정에서 그대로 가져오고, 모르는 건 솔직하게 전화로 넘깁니다.

덤으로 API 비용이 0원입니다. 손님이 아무리 많이 물어봐도 요금이 안 늘어납니다.
