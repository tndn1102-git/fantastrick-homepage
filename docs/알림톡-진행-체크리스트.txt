판타스트릭 알림톡 진행 체크리스트 (2026-08-10)
================================================================

[0단계] 카카오톡 채널이 있는지 먼저 확인  ← 여기가 진짜 시작점
----------------------------------------------------------------
  알림톡은 "인증된 비즈니스 채널"에서만 나갑니다. 채널이 없으면
  가비아 상품을 사도 못 씁니다. 그래서 이것부터 봅니다.

  center-pf.kakao.com 접속 → 로그인
    · 채널이 있다  → [관리] → [비즈니스 채널 신청] → 신청하기
    · 채널이 없다  → 채널 먼저 만들기(무료) → 위와 동일

  비즈니스 채널 심사에 사업자등록증이 필요합니다.
  [상세설정]에서 "검색용 아이디"를 확인해 두세요. 나중에 씁니다.
  채널홈 공개설정은 전부 ON 이어야 합니다.

[1단계] 가비아 알림톡 상품 신청·결제  ← 유료
----------------------------------------------------------------
  message.gabia.com/kakao-notice/  (부가세 포함 가격)

    알림톡  1,000건 + 문자  1,000건 =  31,350원   ← 추천
    알림톡  3,000건 + 문자  3,000건 =  89,760원
    알림톡  5,000건 + 문자  5,000건 = 144,100원
    알림톡 10,000건 + 문자 10,000건 = 278,000원대

  왜 제일 작은 것을 추천하나:
    · 실제 예약량이 월 300건 정도입니다(기존 사이트 실측).
    · 1,000건이면 약 3개월치입니다.
    · 큰 걸 사도 단가가 5%밖에 안 싸집니다. 미리 묶어둘 이유가 약합니다.
    · 유효기한이 없고 수수료 없이 환불되니, 모자라면 그때 더 사면 됩니다.
    · 문자는 지금 880건이 남아 있어 한동안 안 사도 됩니다.

  ※ 신청 후 가비아 담당자가 전화를 겁니다(아웃콜). 승인까지 2~3일.

[2단계] 발신프로필 등록
----------------------------------------------------------------
  관리툴에서 카카오 채널을 연결합니다.
  0단계에서 확인한 "검색용 아이디"와 채널 관리자 인증이 필요합니다.

[3단계] 템플릿 등록 → 카카오 심사 (2~5 영업일)
----------------------------------------------------------------
  관리툴 > 환경 설정 > 알림톡 템플릿 > 등록

  [템플릿 이름]  예약확정안내

  [템플릿 내용] ↓ 아래 상자 안을 그대로 붙여넣기
  ----------------------------------------------------
  [판타스트릭] #{이름}님, 예약이 확정되었습니다.

  ▶ 테마 : #{테마}
  ▶ 일시 : #{날짜} #{시간}

  예약 시간 10분 전까지 도착해 주세요.
  방문해 주셔서 감사합니다.
  ----------------------------------------------------

  ⚠️ 변수 순서 — 이것만은 꼭 지켜주세요
       1번째  #{이름}
       2번째  #{테마}
       3번째  #{날짜}
       4번째  #{시간}

     가비아 알림톡은 변수를 "이름"이 아니라 "순서"로 채웁니다.
     순서가 바뀌면 손님에게 이름 자리에 날짜가 찍힌 문자가 나갑니다.
     홈페이지 코드가 이 순서에 맞춰져 있습니다. 바꾸시려면 꼭 알려주세요.

  심사 반려되는 흔한 이유
    · 할인·이벤트·홍보 문구 (정보성만 됩니다)
    · "채널 추가해주세요" 같은 유도 문구
    · 고정 문구 없이 변수만 있는 경우 (지금 초안은 충분합니다)

[4단계] 마무리 — 제가 합니다
----------------------------------------------------------------
  승인되면 템플릿 번호(숫자)가 나옵니다. 그 번호만 알려주세요.
  홈페이지에 넣는 순간부터
    카톡 되는 손님 → 알림톡
    카톡 안 되는 손님 → 자동으로 문자
  로 갈립니다. 코드는 더 안 건드려도 됩니다.

  ※ 실패한 건은 과금되지 않습니다(가비아가 건수를 복원).
