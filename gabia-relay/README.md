# 가비아 문자 중계소

새 홈페이지(Cloudflare)에서 **가비아 문자·알림톡**을 쓰기 위한 파일입니다.

## 왜 필요한가

가비아 문자 API는 **"발송 서버 IP"를 미리 등록**해야 받아줍니다. 공식 문서 첫 줄에 이렇게 적혀 있어요.

> API 를 연동하기 전, 관리툴에서 **발송 IP**, 발신번호등록, API Key를 먼저 설정하세요.

그런데 Cloudflare는 **나가는 주소가 매번 바뀝니다.** 등록할 주소가 없어요.
(예전에 알리고에서 `인증오류-IP`를 맞았던 그 문제와 같습니다.)

## 그런데 중계소가 꼭 필요한 건 아닐 수 있습니다

IP 검사가 실제로 얼마나 빡빡한지는 **해보기 전엔 모릅니다.** 그래서 순서가 이렇습니다.

```
1단계  API 키만 받아서 Cloudflare에서 바로 시험     ← 문자 안 나감, 돈 안 듦
         │
         ├─ 되면  → 중계소 필요 없음. 이 폴더는 안 씁니다.
         └─ 막히면 → 2단계로
2단계  이 send.php 를 가비아 서버에 올림
```

**1단계 시험 방법** — 관리자로 로그인한 상태에서 `/api/admin/gabia-test` 를 엽니다.
토큰 발급과 잔여건수 조회만 해봅니다. **문자는 한 통도 나가지 않고 요금도 안 듭니다.**

| 결과 | 뜻 |
|---|---|
| `{"ok":true, ...}` | 직접 부를 수 있음 → 중계소 불필요 |
| `step:"토큰"` + IP 관련 오류 | IP 검사에 막힘 → 중계소 필요 |
| `step:"열쇠"` | 아직 키를 등록 안 함 |

## 2단계 — 올리는 방법

### 어디에 올리나

**주소가 고정된 서버면 어디든** 됩니다. 지금은 `fantastrick.co.kr`이 올라가 있는 **가비아 웹호스팅이 제일 쉽습니다.**
그 서버 주소는 **이미 가비아 문자에 등록돼 있어서** 따로 등록할 것도 없습니다.

> 홈페이지 내용은 다 지워도 됩니다. **이 파일 하나만** 살아 있으면 문자는 나갑니다.
> 즉 웹호스팅은 유지하되, 홈페이지로는 안 쓰는 상태로 둘 수 있습니다.

### 순서

1. `send.php` 위쪽 **설정 4줄**을 채웁니다.

   | 항목 | 어디서 찾나 |
   |---|---|
   | `SMS_ID` | 가비아 문자 관리툴 로그인 ID |
   | `API_KEY` | 관리툴 › 관리자 › 서비스 정보 › 관리 중인 서비스 › **API 인증키 정보** |
   | `SENDER` | 관리툴 › 환경 설정 › **발신 번호** (숫자만, 하이픈 없이) |
   | `RELAY_KEY` | 아무 문자열이나 길게(20자 이상). 홈페이지 쪽에도 같은 값을 넣습니다 |

2. FTP로 올립니다. 눈에 안 띄는 폴더가 좋습니다. 예: `/relay/send.php`

3. 브라우저로 그 주소를 열어봅니다.
   `{"code":"ready", ...}` 가 보이면 정상입니다. (GET으로는 문자가 안 나갑니다)

4. **그 주소와 `RELAY_KEY`를 알려주세요.** 홈페이지에 연결하겠습니다.

## 안전장치

- `RELAY_KEY`가 맞아야만 받습니다. 주소를 알아도 열쇠가 없으면 못 씁니다.
- **발신번호는 이 파일이 넣습니다.** 밖에서 바꿔 끼울 수 없습니다.
- 정해진 칸(`phone`·`message`·`subject`·`template_id` 등)만 통과시키고 나머지는 버립니다.
- ⚠️ 이건 **문자를 보내는 창구**입니다. 주소를 아무 데나 적어두지 마세요.

## ⚠️ 기존 사이트를 건드리는 문제

`fantastrick.co.kr`은 **아직 진짜 손님이 예약하는 사이트**입니다. 원칙은 "읽기만 한다"예요.

이 파일은 **새 폴더에 새로 올리는 파일**이라 기존 사이트의 어느 부분도 바꾸지 않습니다.
그래도 그 서버에 파일을 올리는 일이니, **기존 사이트를 내린 다음에 하는 것이 가장 안전**합니다.
급하면 지금 올려도 되지만, 기존 워드프레스 파일은 **하나도 건드리지 마세요.**
